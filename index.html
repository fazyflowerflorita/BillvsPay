Bill vs Pay Reconciliation

This repository contains a Python web app that reconciles Payroll and Billing Excel files.

GitHub Pages can show this page, but it cannot run the Python upload and reconciliation process.

To get a working website link, deploy this GitHub repository to Azure App Service or Render.

1. Keep this repository private if it contains payroll or billing configuration.
2. Create a Python web app in Azure App Service or Render.
3. Connect the service to this GitHub repository.
4. Use start command: python app/server.py
5. Set environment variable: HOST=0.0.0.0
